# 말·기수 사진/일러스트 사용 검토 (2026-10-21, 참고용 · 법률 자문 아님)

## 결론 요약
- **KRA 사진 그대로 사용: 불가(허락 필요).** KRA 홈페이지 사진은 공공누리 표시가 없는 한 KRA 저작물이고 사전 허락이 필요함. 공공누리 1유형(출처표시)만 상업·변경 이용 가능, 2유형(비영리)·3유형(변경금지)·4유형(비영리+변경금지)은 유료 서비스·각색에 부적합.
- **data.go.kr KRA API**: 지금 쓰는 출마표·성적·기수 API에는 사진(이미지 URL) 필드가 없음(실제 응답 확인). 이미지는 API 이용허락 범위 밖으로 봐야 함.
- **실존 기수 사진을 보고 애니풍으로 그리기: 동의 없이는 비권장.**
  1. 저작권: 원 사진에 의거하고 구도·포즈·표정 등 창작적 표현이 실질적으로 유사하면 복제권/2차적저작물작성권 침해(대법원 2007다63409 등). 화풍만 바꿔도 사진 구도를 따르면 위험.
  2. 초상권: 판례상 인정되는 인격권. 식별 가능한 얼굴을 그림으로 그려도 본인을 알아볼 수 있으면 해당.
  3. 퍼블리시티권: 2021.12.7 개정(2022.6.8 시행) 부정경쟁방지법 제2조제1호에 "국내에 널리 인식되고 경제적 가치를 가지는 타인의 성명, 초상, 음성, 서명 등 그 타인을 식별할 수 있는 표지를 공정한 상거래 관행이나 경쟁질서에 반하는 방법으로 자신의 영업을 위하여 무단으로 사용"하는 행위가 부정경쟁행위로 신설(신설 당시 타목, 이후 목 추가로 '파목'으로 인용되는 자료 있음 — 시행 원문으로 목 번호 재확인 필요). 유료 앱 홍보용 캐릭터는 '영업을 위한 사용'에 해당할 수 있음. 2022.6 시행 민법 개정안의 인격표지영리권 신설은 국회 미통과로 알고 있음(재확인 필요).
  - 반면 **기수 이름·성적을 정보로 표시**하는 것(출마표 등)은 공공데이터 이용 범위의 사실 정보라 일반적으로 문제 소지 낮음.
- **실존 말**: 말 자체는 저작물이 아니고, 국내·일본 모두 동물(물건)의 퍼블리시티권을 인정한 확정 판례 없음(일본 최고재 2004 갤럽레이서 사건 — 마명 무단사용 손배 기각). 다만 ① 말 사진은 촬영자 저작권, ② 마명이 상표 등록돼 있으면 상품·서비스 표장으로 쓰는 건 상표권 문제(정보 표시 목적의 마명 기재는 상표적 사용 아님으로 볼 여지 큼), ③ '우마무스메'처럼 의인화 상품은 마주 허락을 받는 업계 관행이 있음.

## 안전한 선택지 (권장 순)
1. **현재 방식 유지**: 실존 인물·말을 닮지 않은 범용 SVG 아바타(구현됨). 화면에 "실제 인물이 아닌 기본 일러스트" 표기.
2. **완전 오리지널 캐릭터**: 사진을 참조하지 않고 그린 가상 기수 캐릭터(jockey_m1~m4, f1~f4)를 *마스코트*로 쓰고, 실존 기수에 매핑하지 않음. 매핑할 경우 아래 3번 필요.
3. **본인 서면 동의 + 사진 저작권자 허락**: 기수 본인(초상·퍼블리시티) 동의서 + 원 사진 저작권자(KRA·사진가) 허락, 또는 우리가 직접 촬영/본인 제공 사진 사용. 대가·범위·기간·철회 조항 포함.
4. **KRA 정식 제휴/라이선스**: 사진·영상 사용 문의(KRA 홍보 부서).
5. 말 일러스트: 털색만 반영한 범용 실루엣 정도는 저위험. 특정 사진 모사 금지, 마명을 로고처럼 쓰지 않기, 의인화 굿즈는 마주 허락.

## 구현 메모
- `art/jockeys/map.json` 에 `{jkNo: 파일명}` 을 넣으면 해당 기수 카드에 이미지 표시. **동의 확보 전에는 실존 기수 번호에 매핑하지 말 것.**
