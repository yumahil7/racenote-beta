# 레이스노트 베타 (racenote-beta)
경마 기록·통계 **정보 전용** 무료 베타 PWA. 베팅·마권·배당 기능 없음. 만 19세 이상.

- 데이터: `data/sample.json` = **가상 예시 데이터** (data.go.kr 한국마사회 API 필드 구조 참고, 배당 필드 제외)
- 수집 스텁: `scripts/fetch-kra.mjs` (서비스키는 환경변수, 커밋 금지)
- 결제: 토스페이먼츠 결제위젯 v2 **문서용 테스트 키** — 실제 청구 없음. 결제 승인(confirm)은 시크릿 키가 필요한 서버 단계로 미구현 → 추후 Cloudflare Workers.
- 한국마사회의 공식 서비스가 아니며 제휴 관계가 없습니다.
